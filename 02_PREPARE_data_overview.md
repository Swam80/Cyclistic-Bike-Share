## Data Source
The dataset is publicly available bike trip data provided by Motivate International Inc., used under an open data license.

## Time Period
The analysis uses 12 months of data covering a full calendar year to capture seasonal trends.

## Data Structure
Each record represents a single bike trip and includes information about:
- Ride start and end timestamps
- Rider type (casual or member)
- Bike type
- Start and end station information

## Key Fields
- ride_id
- rideable_type
- started_at
- ended_at
- start_station_name
- end_station_name
- member_casual

## Data Limitations
- No demographic information (age, gender, income)
- No pricing or revenue data
- No long-term rider history beyond the current dataset
